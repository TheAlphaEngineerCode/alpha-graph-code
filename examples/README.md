# Exemplos

Grafos de demonstração, escritos à mão, para ler antes de escrever o primeiro.

Diferente de [`packages/templates`](../packages/templates), que são grafos de referência
distribuídos com o projeto e cobertos por golden test, os exemplos aqui servem para explicar um
conceito por vez — um exemplo de reducer sob fan-in, um de ciclo com `maxNodeVisits`, um de
aprovação humana com timeout.

_Vazio: os primeiros exemplos chegam com a Fase 2, quando existir validador para provar que
estão corretos. Exemplo que ninguém valida é exemplo que ensina errado._
